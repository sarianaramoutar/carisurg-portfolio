# Data Folder
This folder contains datasets used during the CariSurg Healthcare AI Training Programme.

## Contents
- `week0_emergency_triage_dataset_reduced_dirty.csv`

## Description
The Week 0 dataset contained emergency triage data used for data cleaning, exploratory data analysis and visualisation exercises. 

## Usage
The dataset can be loaded into Python using `pandas`:

``` bash
import pandas as pd 

df = pd.read_csv("data/week0_emergency_triage_dataset_reduced_dirty.csv")
```
