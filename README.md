# CariSurg Portfolio

## Overview

This repository contains coursework completed during the CariSurg Healthcare AI Summer Programme.

The project focuses on emergency department triage systems, clinical data analysis and AI-assisted clinical decision support.

## Repository Structure

### notebooks/

Contains Week 0 exploratory data analysis work.

### docs/

Contains research work and proposal documents.

### data/

Reserved for datasets used throughout the programme.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
